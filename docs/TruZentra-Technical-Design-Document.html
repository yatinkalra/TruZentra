1. Architecture Overview

TruZentra is a multi-layer application built on Salesforce Financial Services Cloud (FSC) with Agentforce as the conversational AI engine.

Presentation Layer

Agentforce Chat UI, LWC Dashboards, Branded Emails, Experience Cloud Site

AI Agent Layer

GenAI Planner Bundle, 10 Topics, 22+ Actions, Prompt Templates

Orchestration Layer

22 Autolaunched Flows connecting Agent to Apex Services

Service Layer

41+ Invocable Apex Classes with full unit test coverage

Data Layer

FSC Standard Objects, Custom Objects, Custom Metadata Types

Data Cloud Layer

Data Lake Objects, Data Model Objects, Calculated Insights

Request Flow

Customer Message
  → Agentforce Planner (GenAI Planner Bundle)
    → Topic Selection (e.g., LoanRestructuring)
      → Action Invocation (Flow: Zentra_Simulate_Restructuring)
        → Apex Service (ZentraLoanSimulateService)
          → SOQL / DML on FSC Objects
            → Response formatted → Agent displays to customer

3. Authentication & Security

3.1 OTP Flow

  1. Customer provides mobile number
  2. ZentraAccountLookupService matches Account using phone variants (with/without +91 country code)
  3. ZentraOTPService generates 6-digit OTP, creates Zentra_OTP_Session__c, sends branded email
  4. Customer submits OTP → ZentraOTPVerifyService validates, generates session token, returns VerifiedCustomerId

3.2 MPIN Flow

  1. Customer provides mobile + 4-digit MPIN
  2. ZentraMPINService validates against Account.MPIN__c
  3. 3-attempt lockout with 30-minute cooldown
  4. On success: returns VerifiedCustomerId, sends MPIN login notification email

3.3 Security Controls

  • OTP Expiry: 5 minutes
  • Max Attempts: 3 per session (OTP and MPIN)
  • Lockout Duration: 30 minutes
  • Session Tokens: UUID-based, single-use
  • Loan OTP: Separate OTP flow for high-value actions (loan restructuring submission)
  • Data Scoping: All queries filter by VerifiedCustomerId — enforced at agent variable level

4. AI Agent & Topics

4.1 GenAI Planner Bundle: TruZentra

The agent uses a single Planner Bundle with attribute mappings that auto-wire VerifiedCustomerId into every action. This ensures no action can execute without verified identity.

4.3 Agent Instructions

  • Verification-first: Every action requires VerifiedCustomerId. Agent redirects to OTP if not set.
  • Language matching: Every topic instruction includes "reply in customer's language"
  • Post-task menu: After every completed action, agent displays 8-option menu
  • Culturally warm: Uses "ji", "please", "dhanyavaad" in all interactions
  • 90-day cooldown: Loan details check for cooldown warning — agent skips simulation if present

8. Email Engine

All emails are sent through ZentraEmailService which uses a CMDT-driven architecture:

  • Master Record: Global branding (brand colour, accent, bank name)
  • Per-Type Records: Override subject, heading, intro text, enable/disable toggle
  • Branded HTML: Inline-styled responsive HTML with custom branding
  • Org-Wide Email: Uses configured Org-Wide Email Address for sender identity

9.2 Churn Risk Calculated Insight

Zentra_Customer_Churn_Risk is a Calculated Insight that computes a real-time churn risk score (0–100) for every customer by analysing:

  • Account activity (active vs. inactive accounts)
  • Recurring payment health (stopped vs. active)
  • Open dispute count
  • Transaction frequency
Scoring Logic:
  No accounts at all         → +80
  Any inactive account       → +30
  More stopped than active RP → +25
  Any open dispute           → +20
  Zero transactions          → +15
  < 5 transactions           → +5

10. Dashboards

10.1 TruZentraOps (zentraRMDashboard)

Customer 360 Operations Console for Relationship Managers:

  • Customer search by name, phone, or email
  • Profile sidebar with quick stats (total balance, liability, account count)
  • Tabbed interface: Financial Accounts, Transactions, Recurring Payments, Loans, Disputes, SIPs, Error Logs
  • Data tables with show-more/collapse and formatted currency

10.2 Data Cloud 360 (zentraDataCloudDashboard)

Unified customer view powered by Data Cloud:

  • Queries DLO objects for cross-platform data
  • Churn risk score display from Calculated Insights
  • Profile, accounts, transactions, recurring payments, disputes, loan requests

11. Error Handling & Logging

ZentraErrorLogger provides centralised error tracking:

  • Every Apex service wraps operations in try-catch and logs to Zentra_Error_Log__c
  • Captures: Class Name, Method Name, Error Message, Stack Trace, Related Record Id
  • Visible on the TruZentraOps dashboard under "Error Logs" tab
  • ZentraErrorLoggerAction exposes logging as a Flow-invocable action

12. Multilingual Support

  • Languages: English, Hindi (Devanagari), Hinglish
  • Detection: Agent auto-detects customer's language from input
  • Response: Every topic instruction mandates matching the customer's language
  • Cultural Nuance: Honorifics (ji), warm greetings, Indian currency format (₹)
  • Intent Recognition: Hindi/Hinglish intent keywords mapped in every topic (e.g., "EMI kam karo", "kisht badlo")

13. Human-AI Handoff

  • Escalation Triggers: Customer requests live agent, or AI cannot resolve
  • Context Preservation: Full conversation history and verified customer ID passed to agent
  • Routing: Zentra_Service_Route_To_Work flow handles Omni-Channel routing
  • Agent Console: TruZentraOps dashboard available to receiving agent for instant 360 view

14. Deployment & CI/CD

  • Source Format: Salesforce DX (sfdx-project.json)
  • Package Directory: force-app/main/default
  • Deploy Command: sf project deploy start --source-dir Zentra-Works --target-org [alias]
  • CI/CD: GitHub Actions workflows for branch cleanup, CICD pipelines
  • Test Data: ZentraSetupCustomer.run(firstName, lastName, email, phone) generates full customer profile
  • Target Org Alias: AF
